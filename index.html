Wet Mix Studio · Smudge Engine

Brush Blend mixes and drags existing paint using the selected brush tip. Low strength blends gently; high strength pulls pigment. Vector Pull is an optional mode that bends ink without softening it. On raster-only layers both methods use pigment blending.

Drag from existing paint to blend colors or pull pigment. Strength controls intensity; pressure also changes it. Soft Haze softens edges, Wet Paint mixes colors, and Finger Pull makes stronger smears. Target chooses the first ink layer or your selected layer. Selection and alpha lock limit edits.
